What it does

Neural mesh

Fully connected neurons that talk to each other, with signals you can watch travel.

Mixture of experts

A router wakes only the specialist that fits the request, so it stays fast and small.

Raw bits, no tokenizer

Text, audio and images all enter the mesh as the bits they already are.

Self-improving

Patterns that keep repeating are promoted to permanent skills; repeated mistakes are penalised.

Local-first and private

One engine on your computer in its own window. No account, no cloud, no open network port.

Extensions and skills

Plug a skill in, change it or combine it without touching the core.

Run it from source: npm run app opens it in its own window. npm run package builds the installer for your system.
